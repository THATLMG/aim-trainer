# Aim Trainer

A small Windows aim trainer with game profiles for Minecraft, Roblox, CS2, Valorant, Fortnite, Overwatch 2 and Apex Legends.

**[Download the latest version](https://github.com/THATLMG/aim-trainer/releases/latest)**: grab `AimTrainer.zip`, unzip it and run `AimTrainer.exe`. If Windows shows "Windows protected your PC", click **More info → Run anyway**.

## Modes
- **Tracking**: keep your crosshair on a moving ball.
- **Flick**: snap to targets as they pop up.
- **Bots**: strafing and standing capsule bots with 3 HP. Headshots kill instantly.
- **Reaction**: click the moment the screen turns green.
- **Sens finder**: blind test to find the sensitivity you aim best with.

## Music
The music bar shows what's playing in Spotify, YouTube, Apple Music and most other players, with previous, play/pause and skip buttons. Click **Lyrics** for lyrics that follow along with the song (from [LRCLIB](https://lrclib.net)). Turn it off with **Music: On/Off** on the home screen.

After each round a sensitivity coach suggests a better sens for your game, and you get a score code for the leaderboard.

## Updates
The app checks this repository when it starts. When a new release is out, it shows **Update now** and updates itself.

Needs Windows 10 or 11.
